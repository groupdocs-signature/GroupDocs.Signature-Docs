GroupDocs provides unlimited free technical support for all of its products. Support is available to all users, including those evaluating the product. You can access support at the [Free Support Forum](https://forum.groupdocs.com/) and the [Paid Support Helpdesk](https://helpdesk.groupdocs.com/).

{{< alert style="info" >}}
Please note that GroupDocs does not offer technical support by phone. Phone support is available only for sales and purchase inquiries.
{{< /alert >}}

## GroupDocs Free Support Forum

If you need assistance with GroupDocs.Signature, please consider the following:

* Ensure you are using the latest version of GroupDocs.Signature before reporting an issue. Check [PyPI](https://pypi.org/project/groupdocs-signature-net/) or the [release notes](https://releases.groupdocs.com/signature/python-net/release-notes/) for the latest version.
* Look through the forums, this documentation, the [Troubleshooting]({{< ref "signature/python-net/getting-started/troubleshooting/_index.md" >}}) page, and the [API Reference](https://reference.groupdocs.com/signature/python-net/) before reporting an issue: your question may already be answered.
* Post your question in the [GroupDocs.Signature Free Support Forum](https://forum.groupdocs.com/c/signature). Questions are answered directly by the GroupDocs.Signature development team.
* Please allow for time zone differences when waiting for a reply on the forums.

## Paid Support Helpdesk

Paid support requests are given higher priority than free support requests.

* Post your question at the [Paid Support Helpdesk](https://helpdesk.groupdocs.com/) to receive higher priority assistance.

## Report an Issue or Feature Request

To ensure your issue, question, or feature request is resolved efficiently, please follow these steps:

* Attach the original document and the code snippet that reproduces the issue. If you need to attach several files, compress them into a single archive. It is safe to attach documents on the GroupDocs Forum, as only you and GroupDocs developers will have access to them.
* Include details about the environment where the issue occurs: operating system, Python version, and the `groupdocs-signature-net` version (`pip show groupdocs-signature-net`).
* Report one issue per thread. If you have additional questions, issues, or feature requests, please create a separate thread for each.
