GroupDocs.Signature for Java lets you add electronic signatures to your documents from Java code. Whether you need to sign contracts, agreements, or any other type of document, you can sign, verify, and manage digital signatures, keeping the integrity and authenticity of your documents.

* ability to e-sign PDF, Word, Excel, presentation and other document formats
* ability to e-sign VBA macros in the documents
